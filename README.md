# دوروسي — واجهة تسجيل الدخول (نسخة مطابقة للتصميم)

نسخة مستوحاة من صفحة تسجيل الدخول في [douroussi.com/auth/sign-in](https://douroussi.com/auth/sign-in):
واجهة عربية كاملة (RTL) بجودة إنتاجية، مبنية بـ HTML/CSS/JS خالص بدون أي تبعيات أو خطوة build.

## الصفحات

| الصفحة | الوصف |
| --- | --- |
| `index.html` | تسجيل الدخول: البريد الإلكتروني، كلمة المرور، تذكّرني، نسيت كلمة المرور، رابط إنشاء حساب، بطاقة تطبيق الهاتف. |
| `sign-up.html` | إنشاء حساب جديد: الاسم الكامل، البريد، كلمة المرور + التأكيد، الموافقة على الشروط. |

## المعاينة محليًا

```bash
python3 -m http.server 8000
# أو
npx serve .
```

ثم افتح `http://localhost:8000`.

## أين أعدّل الأشياء

- **الألوان والخطوط والظلال:** كلها متغيرات CSS في أعلى `styles.css` داخل `:root`
  (`--brand`, `--brand-800`, `--gold`, …). تغيير متغير واحد يغيّر هوية الصفحة بالكامل.
- **النصوص:** مباشرة في ملفَي HTML (كلها عربية وRTL).
- **منطق النموذج:** `script.js` — التحقق من الحقول، إظهار/إخفاء كلمة المرور، حالة التحميل، والتنبيه (toast).

## ملاحظات

- لا يوجد اتصال بخادم: إرسال النموذج يحاكي طلبًا ناجحًا بعد ~1.1 ثانية (نسخة تجريبية).
  للربط بمشروعك الحقيقي، استبدل `setTimeout` داخل `form.addEventListener("submit", …)` في `script.js` بطلب `fetch` إلى `/api/auth/sign-in`.
- التصميم متجاوب (هاتف/تابلت/سطح مكتب)، ويدعم `prefers-reduced-motion`، وتركيز لوحة المفاتيح
  (`focus-visible`) و`aria-*` على الحقول وزر إظهار كلمة المرور.
- الصور/الشعار مرسومة كـ SVG داخلي، لذا لا حاجة لأي ملفات صور خارجية.
