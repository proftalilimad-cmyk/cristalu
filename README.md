# دوروسي — نسخة كاملة من المنصة (Clone)

نسخة مستوحاة من [douroussi.com](https://douroussi.com) — منصة تعليمية عربية (RTL) كاملة،
مبنية بـ HTML / CSS / JavaScript خالص: **بدون أي تبعيات، وبدون خطوة build**.

> محتوى الدروس هنا **نموذجي** (عناوين برامج دراسية معروفة + نصوص مكتوبة لهذا المشروع)،
> وليس منقولًا من المنصة الأصلية. ضع دروسك وملفاتك الخاصة في `data.js`.

## الصفحات

| الملف | الصفحة |
| --- | --- |
| `index.html` | الصفحة الرئيسية: هيرو + بحث، المواد، دورات مختارة، كيف تعمل المنصة، حصص مباشرة، دورات مجانية، الأساتذة، شهادات، التطبيق، دعوة للتسجيل |
| `courses.html` | كل الدورات مع فلترة (مادة / مستوى / بحث) وعدّاد نتائج |
| `course.html?course=math-3as` | تفاصيل الدورة: المحتوى، الدروس المقفلة/المجانية، الأستاذ، بطاقة الاشتراك |
| `lesson.html?course=math-3as&lesson=3` | صفحة الدرس: مشغّل وهمي، تبويبات (نظرة عامة / الملفات / ملاحظاتي)، إتمام الدرس، قائمة الدروس |
| `exams.html` | الاختبارات والتقييمات مع فلترة حسب المادة |
| `dashboard.html` | لوحة المتعلّم: التقدّم، هدف الأسبوع، «واصل من حيث توقفت»، الحصص القادمة، الإنجازات |
| `sign-in.html` | تسجيل الدخول (واجهة مقسومة كما في المنصة الأصلية) |
| `sign-up.html` | إنشاء حساب جديد |

## التشغيل

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> الصفحات تتشارك الهيدر والفوتر عبر `app.js`، لذا شغّلها من خادم (لا تفتحها بـ `file://`).

## البنية

```
index.html  courses.html  course.html  lesson.html  exams.html  dashboard.html
sign-in.html  sign-up.html
styles.css   ← المتغيّرات + أنماط صفحات الدخول
app.css      ← أنماط الموقع (الهيدر، الأقسام، البطاقات، اللوحة…)
data.js      ← كل البيانات: المواد، الأساتذة، الدورات، الدروس، الاختبارات، الحصص
app.js       ← الهيدر/الفوتر + عرض البيانات + التفاعلات
script.js    ← منطق نماذج الدخول/التسجيل فقط
```

## أين تعدّل

- **الألوان:** متغيّرات `:root` في `styles.css` (`--brand`, `--gold`, …) — تغيير واحد يغيّر الهوية كلها.
- **المواد والدورات والدروس:** `data.js`. أضف كائنًا جديدًا في `courses` بنفس الحقول
  (`slug`, `title`, `subject`, `teacher`, `level`, `price`, `lessons[]` …) وسيظهر تلقائيًا في
  الصفحات والفلترة ولوحة المتعلّم.
- **النصوص الثابتة:** مباشرة في ملفات HTML.
- **الربط بخادم حقيقي:**
  - تسجيل الدخول/التسجيل: استبدل `setTimeout` في `script.js` بطلب `fetch('/api/auth/...')`.
  - الدروس: استبدل مشغّل الفيديو الوهمي في `lesson.html` بـ `<video>` أو مشغّل HLS.
  - الاشتراك: اربط زر `#enroll-btn` في `app.js` بواجهة الدفع الخاصة بك.

## ملاحظات تقنية

- تصميم متجاوب كامل (هاتف / تابلت / سطح مكتب) + قائمة جوال منسدلة.
- إتاحة: `aria-*`، تركيز لوحة المفاتيح (`focus-visible`)، رابط «تجاوز المحتوى»،
  واحترام `prefers-reduced-motion`.
- لا صور خارجية: الشعار، الأيقونات، أغلفة الدورات والصور الرمزية كلها SVG/CSS.
- رسوم متحركة خفيفة عند التمرير (`IntersectionObserver`).
- زر «تذكير»، التحميلات، والاختبارات تعرض تنبيهات (toast) تجريبية.
